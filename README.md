# Monster Fusion Masters

**Showcase repository:** `monster-fusion-masters-showcase`

![Monster Fusion Masters showcase cover](assets/showcase-cover.png)

**Play / Live Game:** [https://mfm.monster-fusion-masters-online.workers.dev/](https://mfm.monster-fusion-masters-online.workers.dev/)

Monster Fusion Masters is an original competitive strategy board game. Its physical, 3D-printable edition was first published in 2020: [Monster Fusion Masters V1 board game](https://www.printables.com/model/35556-monster-fusion-masters-v1board-game).

The original game concept, rules, balance design, and physical edition were created before AI tools were involved; they were not generated by AI. In 2020, I did not have video game development experience, and the cost of development made an online version impractical. Earlier efforts to find development help did not move forward because of cost and project scale. In 2026, I began digitizing the long-shelved idea. With Codex's assistance, I have been able to implement it step by step as an online game.

Codex has primarily helped translate the existing rules into code and support multiplayer systems, UI work, debugging, code analysis, and iterative development. It has also helped build supporting features such as ranked play, rooms, and spectator mode. The game design predates and remains distinct from Codex's implementation assistance.

The live game currently includes browser-based gameplay, real-time multiplayer PvP, an AI opponent, ranked play, rooms, spectator mode, a tutorial, and an English / Traditional Chinese interface.

## About this repository

This repository contains selected showcase materials and non-sensitive code examples only.

The complete production source code, game AI, ranking logic, and other core systems are not publicly distributed.

The examples in this folder are small, general-purpose demonstrations. They are not a copy of the production implementation and do not include the game's rules, AI, scoring, matchmaking, security, or server systems.
