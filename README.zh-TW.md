# Monster Fusion Masters

**Showcase 儲存庫名稱：** `monster-fusion-masters-showcase`

![Monster Fusion Masters Showcase 封面](assets/showcase-cover.png)

**遊玩／線上版本：** [https://mfm.monster-fusion-masters-online.workers.dev/](https://mfm.monster-fusion-masters-online.workers.dev/)

Monster Fusion Masters 是一款原創的競技策略棋盤遊戲。實體 3D 列印版本於 2020 年首次公開：[Monster Fusion Masters V1 棋盤遊戲](https://www.printables.com/model/35556-monster-fusion-masters-v1board-game)。

原始遊戲概念、規則、平衡設計與實體版本都在使用 AI 工具之前完成，並非由 AI 生成。2020 年時，我缺乏電子遊戲開發經驗，也受限於開發成本，因此無法完成線上版本。過去曾尋求開發協助，但因成本與專案規模等因素，未能繼續推進。2026 年，我重新開始將這個擱置多年的構想數位化；在 Codex 協助下，逐步將它實作成線上遊戲。

Codex 主要協助把既有規則實作成程式，並支援多人系統、介面、除錯、程式碼分析與反覆開發，也協助完成積分對戰、房間與觀戰等周邊系統。原始遊戲設計早於這段 Codex 實作協作，兩者有所區分。

目前線上版本包含瀏覽器遊玩、即時多人 PvP、AI 對手、積分對戰、房間、觀戰、新手教學，以及英文／繁體中文介面。

## 本儲存庫內容

本儲存庫僅包含精選 Showcase 素材與非敏感的程式碼範例。

完整 production 原始碼、遊戲 AI、排名邏輯及其他核心系統不會公開發佈。

此資料夾中的範例是通用、精簡的示範，並非 production 實作的副本，也不包含遊戲規則、AI、計分、配對、安全或伺服器系統。
